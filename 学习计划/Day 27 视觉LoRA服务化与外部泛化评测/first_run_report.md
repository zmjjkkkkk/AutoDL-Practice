## 服务联调

- 远端服务：`127.0.0.1:8769`
- 本地 SSH 隧道：`127.0.0.1:18769`
- 羊图请求：返回 `sheep`
- 猪图请求：返回 `pig`

服务仅接收 `{ "image_base64", "mime_type" }`，对图片尺寸和 MIME 类型进行限制，只输出 `sheep`、`pig` 或失败状态。它不接收文件路径、URL、额外提示词或任何 Mindcraft 命令，因此与游戏执行链路保持隔离。
