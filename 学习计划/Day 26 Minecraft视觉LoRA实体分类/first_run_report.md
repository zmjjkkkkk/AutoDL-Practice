## 训练与评测

- 基座：`Qwen2.5-VL-7B-Instruct`。
- 方法：视觉语言监督微调中的 LoRA；仅训练集参与 12 个 epoch。
- 输入：最长边缩放为 768；分类输出必须严格为 `sheep` 或 `pig`。
- 基础模型留出集准确率：`13/20 = 65.0%`。
- LoRA 留出集准确率：`19/20 = 95.0%`。

## 残余错误与结论

唯一失败样本的真实标签为 `sheep`，基础模型和 LoRA 都预测为 `pig`。该错误被保留，不使用 `pig -> sheep` 别名、规则补丁或人工回填。

因此，本轮结果证明在当前截图分布上，视觉 LoRA 能显著改善羊/猪精确分类；但由于训练和测试截图来自同一轮采集，不能将 `95.0%` 外推为对其他 Minecraft 世界、实体或拍摄条件的总体准确率。下一轮应使用新会话、不同地形和光照的独立外部测试集复测泛化。
